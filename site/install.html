Wiederherstellung / Recovery

Bei einem fehlgeschlagenen Update ein vorheriges Release auswählen. Wenn nötig BOOT gedrückt halten, USB verbinden und BOOT nach dem Verbindungsaufbau loslassen. „Erase device“ löscht WLAN, Geräteschlüssel und Kalibrierung.
After a failed update, choose a previous release. If needed hold BOOT while connecting USB and release after connecting. Erasing removes Wi-Fi, device key and calibration.

Nach der Installation zeigt das Display den WLAN-Zugangspunkt und das Passwort. Dort WLAN und einen neuen Geräteschlüssel einrichten.
After installation, the display shows the Wi-Fi setup access point and password. Configure Wi-Fi and a new device key there.
